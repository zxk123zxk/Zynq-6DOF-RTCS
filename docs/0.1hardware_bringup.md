## 始终有效的安全规则

- 舵机使用独立电源，不得从 Zynq GPIO 电源轨供电；未测的电压值不得写作实测。
- G1 的 Bank34 VCCIO、BusLinker TTL 空闲电压及独立开关切断效果没有仪器实测记录；不填造数值，不将 ID 1 的临时窗口推广到六轴。
- 硬件急停必须独立于 Linux、PS、PL 软件路径，能够物理阻止执行动作。
- ABI 12 上电默认禁止物理 TX；只有装上 J20-36/W15→J20-38/GND 跳线才能发送。旧 33↔38 接法只属于归档 ABI 02 镜像；实际 `-Ttl` 顶层已编入六轴实测闭区间且 `calibrated_mask=0x3f`，六轴广播受本次参数、限位、总线互斥和速度约束，不使用历史故障闭锁。接线沿用 ABI 06–11：J20-35/V15←BusLinker 丝印 TX、J20-33/U20→丝印 RX。
- 所有关节 ID、零位、方向、限位和性能数据必须来自实测；禁止补写或猜测。
- 自动抓放仅在固定工位点、夹爪角色、负载空间及停止路径已有可复查实测数据后启用；G2 当前缺少的原始日志须如实标注，不补造数值。
