## 当前硬件与接口基线（2026-10-12）

- **板端 ABI = `0x5254000E`**，`physical_tx=ENABLED` 已实测；源码、bitstream、XSA、SD 三件套与板端一致。
- **ID 1–5 为关节舵机，ID 6 为夹爪执行器**（用户 2026-10-12 确认）。因此机械臂为 **5 自由度 + 夹爪**架构：末端位置由 ID 1–3 决定，手腕姿态由 ID 4（俯仰）与 ID 5（自转/偏航）决定，夹爪开合由 ID 6 控制。
  - 结论：**桌面/传送带上的"自上而下抓取 + 偏航对准"完全可由 5 关节实现**，不需要 6 自由度解析逆解。
- **ID 5 已恢复正常行程**：2026-10-12 单轴 `--id 5 --target 1500 --speed-raw 500 --time-raw 100` 由 1907 运动至 1510，`fault=0 in_band=1 unicast_ack=1`，20 样本 1008 ms `timing=WITHIN_2S`。旧的 [1926, 2049] 内部窄窗口已由官方软件重新校准解除；`config/g2_measured_limits.toml` 里 ID 5 的 0–4000 仍是**命令范围标注**，G3 首次实测时应补记真实可用区间。
- **相机 = 幻尔 30 万像素 / 120° 广角 USB 免驱摄像头**（无深度）→ 走 V4L2/UVC，工作分辨率约 640×480。**120° 广角意味着必须做畸变校正并把工作平面限制在图像中央区域**；**本工程因此不使用点云或深度学习抓取检测**（详见 [G4](4.G4-static-vision-grasp.md)）。

## 1. 门禁分两级

### 1.1 红线门禁（任何轨道、任何时候都不得绕过）

- 舵机使用独立电源，不得从 Zynq GPIO 电源轨供电；未测的电压值不得写作实测。
- ABI 0E 上电默认禁止物理 TX；只有装上 J20-36/W15→J20-38/GND 跳线才能发送。
- PL 编译期的目标闭区间、原始速度上限、截止时间与总线互斥检查。
- 硬件急停必须独立于 Linux、PS、PL 软件路径，能够物理阻止执行动作。
- 所有关节 ID、零位、方向、限位和性能数据必须来自实测；禁止补写或猜测。
- 单次提交最多一帧；**不得自动重试**已报 ERR 的运动命令。

### 1.2 流程门禁（**仅归档轨要求，竞赛轨默认关闭**）

- 每步运动前要求操作者逐条填写 `operator_confirmed` 与证据引用（`scripts/g3_offline_plan.py` 的离线任务表检查）。
- 每条命令的完整原始输出归档、每条故障的独立证据文件。
- "位置反馈不能单独证明抓取成功"级别的判定链。
- 100 次静态循环全量记录、P99 抖动统计、长跑统计。

> **历史教训（本仓库真实代价）**：最严重的一次进度拖慢并非红线门禁防住了风险，而是 ABI 0D 的"发前 READ 门禁"把舵机一个**瞬时** ERROR 位放大成跨命令粘滞的**全局锁死**，导致"越试越坏"，把一次几分钟可定位的窄窗口问题拖成多日排查。**门禁要放在防止不可逆动作上（红线），不要放在要求每次都留证据上（流程）。**

## 2. 双轨制：竞赛轨与归档轨

| 轨道 | 目的 | 门禁强度 | 产物 | 节奏 |
| --- | --- | --- | --- | --- |
| **竞赛轨（快）** | 每周产出可演示的功能增量，保证 11.04 与 11.20 两个硬节点 | **只保留 1.1 红线**；1.2 流程门禁全部关闭 | 可运行代码、演示视频、性能数字 | 周一计划 / 周五"能跑起来给人看" |
| **归档轨（慢）** | 满足作品文档、答辩、复盘与可复查性 | 红线 + 全部 1.2 流程门禁 | 原始日志、证据表、历史快照 | 周末集中补 |

**三条硬约定：**

1. **任何流程性门禁不得阻塞竞赛轨的运动路径。** 若某个检查项只产生"证据要求"而不阻止危险动作，它在竞赛轨中不得作为运动的前置条件。
2. **红线门禁永不因赶工期而放宽。** 工期压力只能通过减少功能范围（少做一个工位、少做一次统计）来缓解，不能通过拆掉独立供电、物理禁发或急停来缓解。
3. **接口在 G3 结束时冻结**（PL 寄存器映射、CLI 命令集、`config/` 限位格式），此后只增不改，避免反复重建镜像。需要改变语义时必须升 ABI 并分别构建匹配镜像。

## 3. 始终有效的安全规则

- 舵机使用独立电源，不得从 Zynq GPIO 电源轨供电；未测的电压值不得写作实测。
- G1 的 Bank34 VCCIO、BusLinker TTL 空闲电压及独立开关切断效果没有仪器实测记录；不填造数值。
- 硬件急停必须独立于 Linux、PS、PL 软件路径。
- 接线沿用 ABI 06–12：J20-35/V15←BusLinker 丝印 TX、J20-33/U20→丝印 RX、J20-37 共地；J20-36/W15→J20-38/GND 为物理允许跳线。
- 所有关节 ID、零位、方向、限位和性能数据必须来自实测；禁止补写或猜测。
- 自动抓放只能在固定工位点、夹爪角色、负载空间及停止路径已有可复查实测数据后启用。
- **竞赛轨允许"一次授权、连续执行到失败即停"**，但不允许"无人值守连续跑一整夜"。运动期间必须有人在场并能物理断电。

## 4. 阶段边界

- G2 的结论（六轴到位、ID 5 修复、限位表）是本轮所有阶段的输入基线。
- G3 只在六轴只读诊断全绿后开放运动；G4 只在 G3 单循环跑通后开放视觉；G5 只在 G4 视觉引导静抓达标后开放传送带；G6 只在 G5 跑通后统计。
- **降级路径**：若 G4 视觉未按期达成，11.04 直接使用 G3 的固定工位抓取视频交付；视觉作为增强项顺延到决赛。
