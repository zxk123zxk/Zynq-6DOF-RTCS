> 历史记录：下文是旧 USB/G0 镜像（PL ABI `0x52540001`）的复验笔记，不适用于当前 `artifacts/sd/`。当前复制、启动及 `rtcs-pl-g1 probe` 流程见 [SD 启动与项目迭代操作说明](SD启动与项目迭代操作说明.md)。不要用下文的旧 ID 预期判断新镜像。

以下仅保留旧镜像的历史复验记录；当前仓库已不再提供这组旧文件：

起始输入框处有petalinux-rtcs login: 
输入petalinux，设置密码，建议995995
登录成功后输入框变为petalinux-rtcs:~$

在 shell 提示符下依次执行（USB 接法与当前一致，编号为 1-1、ttyACM0；若重新枚举后变化，先核对实际设备节点）：

    uname -a
    grep '^MemTotal:' /proc/meminfo
    grep '/dev/mmcblk0p1 ' /proc/mounts
    sudo devmem 0x43c00000 32
    zcat /proc/config.gz | grep '^CONFIG_USB_ACM=y$'
    cat /sys/bus/usb/devices/1-1/idVendor /sys/bus/usb/devices/1-1/idProduct
    ls -l /dev/ttyACM0
    command -v rtcs-buslinker-g1

预期依次为 Linux armv7l、约 1028308 kB、SD FAT 分区挂载、0x52540001、CONFIG_USB_ACM=y、1a86/55d3、/dev/ttyACM0、/usr/bin/rtcs-buslinker-g1。任一项不符即停在该项。若需复验 UIO，重启后运行以下三条，预期名称为 rtcs；模块绑定不跨重启保存：

    sudo modprobe -r uio_pdrv_genirq 2>/dev/null || true
    sudo modprobe uio_pdrv_genirq of_id=generic-uio
    cat /sys/class/uio/uio0/name

核对舵机独立电源极性、BusLinker Servo/USB 跳线及急停，固定机械臂，确认上电不会造成机械臂运动。依次测试 ID 1–6；任何失败立即停止：

    for id in 1 2 3 4 5 6; do echo "=== ID $id PING ==="; sudo rtcs-buslinker-g1 --device /dev/ttyACM0 --id "$id" ping || break; echo "=== ID $id READ POSITION ==="; sudo rtcs-buslinker-g1 --device /dev/ttyACM0 --id "$id" read-position || break; done

预期 12 次 RTCS_BUSLINKER_G1_OK、6 个 position_raw，每次 servo_error=0x00。最后关闭舵机电源并断开舵机总线，**保持 BusLinker USB 在线**，做一次故障复验：

    sudo rtcs-buslinker-g1 --device /dev/ttyACM0 --id 1 ping

预期 ERR response_timeout，没有 RTCS_BUSLINKER_G1_OK。若串口节点也消失，此次不能算总线超时验收。所有命令只发送单播 PING/READ；禁止 WRITE、REG_WRITE、ACTION、SYNC_WRITE、RESET、广播、扭矩、速度和目标位置指令。
