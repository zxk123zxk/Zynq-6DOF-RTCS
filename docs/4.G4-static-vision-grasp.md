# 4. G4：动态纠错与最终演示

## 目标

在 G3 静态闭环稳定的基础上，加入 PS 侧视觉、坐标标定、目标预测和端到端性能测量，完成动态抓取演示。

## 计划核心改动

- PS 实现相机标定、像素到世界坐标转换、FK/IK、任务状态机和目标截止时间生成。
- 建立 Linux-only 基线，与 PS-PL 分工后的端到端延迟、P99 抖动和截止时间命中率比较。
- 增加传送带/动态目标条件下的故障注入、长期运行和可复现演示脚本。

## 验收证据

- 动态目标试验的截止时间命中率、端到端延迟和 P99 抖动数据。
- 资源、时序、故障恢复和长期运行记录。
- 可复现的演示步骤、发布版本和报告数据。

## 阶段边界

G4 只在 G3 的安全与静态闭环证据完整后开始；视觉功能不应替代 PL 的急停、看门狗或舵机时序职责。
