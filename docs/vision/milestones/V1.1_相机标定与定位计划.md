# V1.1 固定摄像头标定与工作空间定位计划

## 状态与边界

**状态：待开发。**

本阶段把 V1.0 的原图像素中心 `(u, v)` 转换为固定工作平面中的 `(x_mm, y_mm)`。Workspace frame 必须由现场配置定义，不能冒充 Robot Base frame。本文件不包含真实标定参数或精度结果。

## 主要任务

1. 固定单摄像头、镜头、焦距、分辨率和工作区域，记录实际分辨率、帧率、安装高度、俯视角度与视野。
2. 使用标定板采集多姿态图像，通过 OpenCV 求相机内参和畸变系数，保存分辨率、标定日期、图像集和重投影误差。
3. 评估镜头畸变；需要时对检测输入或待定位点执行一致的去畸变，禁止混用畸变图像与去畸变标定参数。
4. 在实际抓取平面上定义 Workspace frame 的原点、`x/y` 方向和毫米单位。
5. 测量像素点与工作台毫米点的对应关系；使用 OpenCV `getPerspectiveTransform`（恰好 4 点）或 `findHomography`（多于 4 点）求 Homography，并用 `perspectiveTransform` 转换坐标。
6. 使用未参与求解的独立测量点验证定位误差，记录每点误差及 mean、RMS、max。
7. 为标定结果建立有效性检查：图像分辨率一致、矩阵有限且非退化、摄像头配置版本一致、ROI/去畸变状态一致、输入输出有限、目标位于已验证工作区。
8. 摄像头、镜头、分辨率、安装姿态或工作平面发生变化后，标定应失效并重新执行。

## 与 G4 设计的关系

团队 G4 设计提出中心工作区使用、相机标定、平面 Homography 和独立点验证，并给出重投影误差 `<0.5 px`、平面定位误差 `<2 mm` 等建议目标。这些是待现场验证的设计指标，不是当前已取得的结果；最终阈值需结合实际摄像头、视野、目标像素尺寸和抓取容差由团队确认。

## 计划交付物

- 固定摄像头安装与配置记录；
- 原始标定图像清单及质量检查记录；
- 相机内参与畸变配置（含图像分辨率和版本）；
- 工作平面点对及 Homography 配置；
- 独立验证点数据和 mean/RMS/max 误差报告；
- 像素到 Workspace 转换模块及自动测试；
- 标定失效条件、重新标定步骤和现场复现指南。

以上文件名和配置格式应在实施前结合团队仓库现有规范确定，本计划不预先写入虚假参数。

## 验收标准

- 固定摄像头配置可重复安装并被唯一记录；
- 内参/畸变和 Homography 均来自实际测量，不使用示例参数作为正式配置；
- 校准点与独立验证点严格分离；
- 分辨率或配置不匹配时明确拒绝转换，不静默缩放；
- 输出明确标注 `workspace_mm`、坐标轴定义、标定版本和有效性；
- 定位误差达到团队根据抓取需求批准的阈值，并保存原始证据；
- 尚未完成或超出有效区时输出无效状态，不产生伪造毫米坐标。

## 明确不包含

- Workspace 到 Robot Base 的外参变换；
- 物体 `yaw` 估计；
- 逆运动学、轨迹规划、舵机或 FPGA 控制；
- 抓取闭环验收。
