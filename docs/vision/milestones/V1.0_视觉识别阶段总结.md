# V1.0 方块与圆柱体实时视觉识别阶段总结

## 阶段定位

V1.0 是视觉子系统的阶段性交付版本，不代表 Zynq-6DOF-RTCS 整体项目版本，也不代表 G4 视觉抓取闭环已经验收完成。

阶段目标是交付一个可复现的 PC 端视觉模块：识别真实三维 `cube` 与 `cylinder`，在单帧内返回零到多个目标的类别、检测框、置信度和像素中心，并提供图片、视频和 USB Camera 运行入口。

## 已完成的正式功能

- 类别固定为 `0=cube`、`1=cylinder`。
- YOLO A 作为正式基线；OpenCV 几何检测仅作为受控背景、稳定光照和受控姿态下的辅助实验。
- 支持图片目录、本地视频和 USB Camera 输入。
- 支持单帧零到多个目标，不执行异常目标、少数类或多数类筛选。
- 支持可配置 ROI，并将局部检测框和中心恢复为原始完整图像像素坐标。
- 输出 `ObjectDetectionFrame`：帧编号、时间戳及其来源、原图宽高和目标列表。
- 每个 `ObjectDetection` 输出 `class_id`、`class_name`、`confidence`、`bbox_xyxy_px`、`center_px`、`timestamp_s` 和 `valid`。
- 空检测使用空目标列表，不沿用上一帧坐标。
- 实时工具可显示检测框、类别、分数、中心像素坐标、模型耗时和端到端 FPS，并可保存可视化与 JSONL。

坐标采用原图左上角为原点，`u/x` 向右、`v/y` 向下，单位为像素。当前结果不是 Workspace 或 Robot Base 坐标。

## 模型交付

YOLO A 权重位于：

`models/vision/yolo_a_cube_cylinder_best.pt`

- 架构：Ultralytics YOLO11n detection
- 文件大小：5,496,580 bytes
- SHA-256：`2874DF121E6BC780261A27E62C87A14F835E11F60857A2FD4778739398B0BF50`
- 模型来源、数据来源、评估指标和许可证范围见 [YOLO A 模型卡](../model_card_yolo_a.md)。

YOLO B 是原开发工程中的受控对照实验。既有评估显示其效果低于 YOLO A，因此未替换基线，也未作为本次团队仓库的正式权重交付。该结论只用于模型选择记录，不表示 YOLO A 已通过最终传送带场景验收。

## 验证证据

- `tests/vision/` 当前包含 16 项自动测试，覆盖结果契约、空检测、多目标、ROI 坐标恢复、OpenCV 基础几何逻辑和 YOLO 记录适配。
- 迁移交付时从团队仓库完成了 16/16 自动测试、语法与导入检查、两个 CLI 的 `--help` 检查、权重完整性检查和一张合成图片的端到端 YOLO 推理。
- 单图端到端验证只证明模型能够从团队仓库路径加载并产生结构化输出，不等于真实传送带性能验收。
- USB Camera 曾在原视觉开发工程中进行真实运行测试；迁移到团队仓库后尚未重新执行 USB Camera 硬件测试，不能把历史测试描述为本轮迁移验证。
- 已交付基准 commit：`d247a740a06d72a2e512e051a151b5da39f0046f`，分支：`vision-cube-cylinder`。

## 当前限制

- 最终固定俯视摄像头、传送带视野、稳定光照和真实目标尺寸尚未现场验收。
- YOLO A 在跨场景真实图像中已观察到红色 cube 误分类、低对比白色 cube 漏检，以及桌面、线缆和圆形背景误检风险。
- 当前不输出物体 `yaw`。
- 尚未完成真实相机内参、畸变与 Homography 标定，不输出 Workspace 毫米坐标。
- Workspace 到 Robot Base 的变换、目标选择策略、通信协议、机械臂动作和安全联锁不属于 V1.0 实现。
- 未完成机械臂抓取闭环或 G4 静态抓取成功率验收。

## 阶段验收结论

**状态：阶段性交付完成。**

V1.0 已满足“正式视觉源码、YOLO A 权重、USB Camera 入口、统一像素接口、自动测试和复现文档”的工程交付条件。其验收边界止于视觉检测与原图像素位置输出；相机标定、控制端联调和抓取闭环分别由 V1.1、V1.2 和 V2.0 承接。
