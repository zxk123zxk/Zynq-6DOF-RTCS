# V1.1 固定摄像头场景锁定与工作空间定位计划

## 状态与边界

**状态：待开发。**

本阶段把 V1.0 的原图像素中心 `(u, v)` 转换为固定工作平面中的 `(x_mm, y_mm)`。Workspace frame 必须由现场配置定义，不能冒充 Robot Base frame。本文件不包含真实映射参数或精度结果。

**本阶段不做相机内参/畸变标定，也不使用棋盘格标定板**（2026-10-14 决定，理由见 [G4](../../4.G4-static-vision-grasp.md)）：棋盘格角点检出现场不稳定，而工作平面上的实测点对会把镜头畸变一起吸收进映射本身。

## 主要任务

1. 固定单摄像头、镜头、焦距、分辨率、**曝光与白平衡**（关闭自动档或记录锁定值），记录实际分辨率、帧率、安装高度、俯视角度与视野。
2. **锁定现场背景工况**：只对**黄色桌面**与**绿色传送带**两种背景负责；各采集一份纯背景图与含工件实拍图，并记录相机与场景配置版本。
3. **在工作平面上直接测量映射**，不经过内参/畸变校正。点对来源：把工件依次放到平面上若干个**已知工作坐标**的位置，用实际使用的检测器读出像素中心；或由机械臂末端移动到已知坐标后记录像素。
4. 在实际抓取平面上定义 Workspace frame 的原点、`x/y` 方向和毫米单位。
5. 用 ≥6 个点对求映射：点分布铺开时用 `cv2.findHomography`；只在中央区域铺 3×3 网格时用**双线性插值**（对广角畸变更稳）。按实测误差二选一，再用对应函数转换坐标。
6. 使用**未参与求解**的独立测量点验证定位误差，记录每点误差及 mean、RMS、max。
7. 为映射结果建立有效性检查：图像分辨率一致、矩阵/插值网格有限且非退化、相机与场景配置版本一致、曝光锁定状态一致、输入输出有限、目标位于已验证点的**凸包内部**（含边界余量），且背景属于已验收的两种工况。
8. 摄像头、镜头、分辨率、曝光、安装姿态、工作平面或**背景工况**发生变化后，映射失效并重做。

## 与 G4 设计的关系

团队 G4 设计提出中心工作区使用、平面映射与独立点验证，并给出平面定位误差 `<2 mm` 等建议目标。这些是待现场验证的设计指标，不是当前已取得的结果；最终阈值需结合实际摄像头、视野、目标像素尺寸和抓取容差由团队确认。

## 计划交付物

- 固定摄像头安装、曝光锁定与场景配置记录；
- 两种背景（黄色桌面、绿色传送带）的背景图与含工件实拍图，及其点检记录；
- 工作平面点对清单（含坐标来源与测量方式）及求解方法说明；
- 映射配置（矩阵或插值网格）与配置版本；
- 独立验证点数据和 mean/RMS/max 误差报告；
- 像素到 Workspace 转换模块及自动测试；
- 映射失效条件、重做步骤和现场复现指南。

以上文件名和配置格式应在实施前结合团队仓库现有规范确定（约定候选：`config/workspace_plane.yaml`），本计划不预先写入虚假参数。

## 验收标准

- 固定摄像头与场景配置可重复安装并被唯一记录；
- 映射点对与验证点**均来自实际测量**，不使用示例参数作为正式配置；
- **校准点与独立验证点严格分离**；
- 分辨率、曝光锁定或场景配置不匹配时明确拒绝转换，不静默缩放；目标超出已验证凸包时拒绝，不外推；
- 输出明确标注 `workspace_mm`、坐标轴定义、映射版本、有效性，以及**背景工况**；
- 定位误差达到团队根据抓取需求批准的阈值，并保存原始证据；
- 尚未完成或超出有效区时输出无效状态，不产生伪造毫米坐标。

## 明确不包含

- **相机内参、镜头畸变标定与棋盘格/标定板采集**；
- Workspace 到 Robot Base 的外参变换；
- 物体 `yaw` 估计；
- 逆运动学、轨迹规划、舵机或 FPGA 控制；
- 抓取闭环验收。
