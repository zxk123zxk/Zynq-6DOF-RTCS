# 0. G0：PS-PL 基础工程（已完成）

G0 证明 AX7Z020B 可以在**不连接舵机**的安全边界内启动，并建立 PS 到 PL 的基础控制通路。它不是机械臂运动阶段。

## 本阶段核心改动

- 完成板卡型号、PL Bank 电压、收发器逻辑电平、独立舵机电源、共地和硬件急停的 G0 核验；舵机仍保持断开。
- `src/pl/vivado/ax7z020b_ps7_config.tcl` 固化 PS7：DDR3 512 MiB、PS UART1、SD0、`M_AXI_GP0`、`IRQ_F2P` 和 100 MHz `FCLK_CLK0`。
- `src/pl/vivado/create_rtcs_system.tcl` 建立 `PS7 -> AXI Interconnect -> rtcs_axi_wrapper_bd -> rtcs_top`，并通过 `proc_sys_reset` 分发同步低有效复位。
- RTCS 的 PS 可见地址固定为 `0x43C0_0000`，窗口大小 64 KiB；设备树把它登记为 `generic-uio` 外设。
- `src/pl/rtl/axi_lite_regs.sv` 实现 AXI4-Lite 寄存器组；`sim/tb_axi_lite_regs.sv` 已覆盖复位、读写握手、部分字节写和六轴目标寄存器。
- PetaLinux 构建脚本、SD 启动脚本和 `rtcs-uart-smoke` 控制台冒烟应用已加入工程。

## 当前可用数据路径

```text
PS Linux -> M_AXI_GP0 -> AXI Interconnect -> AXI4-Lite register bank
```

软件可见寄存器以 `src/pl/rtl/rtcs_pkg.sv` 与 `src/ps/linux/include/rtcs_registers.hpp` 为唯一事实来源。关键偏移为：`ID_VERSION=0x00`、`CONTROL=0x04`、`COMMAND=0x08`、`TARGET_0..5=0x20..0x34`、`PROFILE_SPEED=0x38`、`PROFILE_ACCEL=0x3c`、`DEADLINE=0x40/0x44`。

## 安全状态与边界

- `src/pl/rtl/rtcs_top.sv` 将 `servo_tx_en` 硬性置零，且 Block Design 包装器不导出任何舵机 IO。
- 当前 `IRQ` 线路、UIO 节点和状态寄存器已预留；RTL 的 IRQ 输出仍恒为低。
- `COMMAND` 当前只被寄存器组保存，尚未连接 FIFO、轨迹、UART 或舵机。
- `rtcs-uart-smoke` 验证的是 PS UART1 控制台和 Linux 应用，不等价于 UIO/MMIO 实测，更不等价于舵机通信。
