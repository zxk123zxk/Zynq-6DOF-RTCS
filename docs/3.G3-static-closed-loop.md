# 3. G3：静态闭环与轨迹

## 目标

实现命令 FIFO、六轴同步轨迹、反馈超时与看门狗，在静态工作站完成安全的抓放闭环。

## 计划核心改动

- 为 `src/pl/rtl/trajectory_engine.sv` 实现经过测量确认的梯形轨迹，并提供截止时间超期报告。
- 在 PL 中连接描述符 FIFO、调度器、舵机总线、反馈解析和安全监控器。
- 将完成、超期、舵机故障和安全故障写入 `IRQ_STATUS`，并以 UIO IRQ 通知 PS。
- PS 实现 UIO/MMIO 命令下发、状态读取、日志和静态抓放状态机。

## 验收证据

- 完整 RTL 回归，包括 FIFO、轨迹、超时、限位、看门狗和反馈故障。
- 100 次静态抓放循环：成功/失败、最大位置误差、人工干预、延迟和抖动数据。

## 阶段边界

G3 只覆盖固定工位的静态闭环，不包含相机动态目标预测或传送带追踪。
