## 4. 一条今天才看清的认识（写报告要用）

把 ID2 逐点斜率算出来（每 25 mm）：**−3.16 / −0.80 / −1.56 / −0.24 / −2.12**；
ID3 是 **+3.40 / +0.60 / +2.20 / −0.36 / +3.28**。

光滑曲线上这些斜率应当单调变化，实际**正负交替** → 说明每个教点自身的手工摆位
重复性只有 **±10 mm 量级**。上午"抓 345 偏 10 mm"的根因在此，**不是插值算法**。

推论（三条都要写进文档，别含糊）：

1. 不必再投入插值算法精度——输入数据没有那个精度；
2. 40 mm 方块 + ±10 mm 教点误差 = 现在稳定命中的真实原因；
3. 想把精度提一个量级，只有两条路：**工位加 y 向参考**（压摆件误差）或**加落点测量闭环**，
   都不是算法问题。

## 6. 已知风险 / 遗留

1. **闭环 0 样本** —— G4 最低线唯一判据，10-26 第一件事。
2. **420 未做带件实抓**：只验过 `diagnose`（教点时），没验过"抓→抬→放→撤"，
   且它的 ID5=2107 是腕部转角最大的一点。
3. **y 不参与插值**：`piecewise_linear` 只读 x，件偏离 y=36 多少落点就错多少。
   "随机摆放"只能随机 x。
4. **区间外夹端点**：越界会用端点姿态并告警，偏 20 mm 以上（= 抓空）。不外推。
5. **精度上限 ±10 mm**（见 §4），换小件会失效。
6. `metrics/` 目录仍不存在（竞赛硬要求：指标表 + 原始证据）。
