**交接纪律（2026-10-21 补，踩过坑）**

1. **不交换 `.venv`**。venv 里写死了创建者的 Python 路径（这次是 `H:\Miniconda`），换机器必然
   报 `No Python at ...`，且那份 venv 里只有 pip、连 torch 都没装。交付只给
   **源码 + `requirements.txt` + 权重**，各自在本机 `python -m venv .venv` 重建。
2. **相机一动就必须重标**。`config/calibration.json` 与机位一一绑定；换机位、调焦、改分辨率
   都要重跑 `scripts/live_calibration.py`。
3. **坐标系统一只认一套**：原点=传送带左下角、+x 沿带长、+y 沿带宽。谁要改，必须在
   `4.G4` 与 `状态机编排层` §9.3 同步改，否则整条链路会静默偏转。

**场景约束（10-14 定，不再变更）**：抓取背景只有**黄色桌面**或**绿色传送带**两种；不打印标定板、
不跑角点检出、不单独求内参，像素→工作坐标用平面四点单应。
