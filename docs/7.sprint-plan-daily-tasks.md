# 冲刺计划与每日任务卡（2026-10-12 → 11-20）

- **硬节点**：**11-04 提交作品文档 + 视频，视频里必须呈现"伪动态抓取"**（传送带运行中抓住移动物块）；11-20 决赛为**真动态**（视觉驱动提前量）。
- **伪动态 vs 真动态**（2026-10-19 定）：
  - **伪动态**＝传送带匀速运行 + 物块从固定起点投放 + 光电开关触发固定延时 T 后定点闭合。机械臂提前就位等物块，看起来是"动中抓"，本质是**时机对准**。
  - **真动态**＝由检测到的位置/速度实时算提前量，T 随物块状态变化。11-20 前完成。
  - 价值论述在 11-04 就要成立：**PS-PL 分工带来的确定性与节拍**，用伪动态的实测数据讲，不等真动态。
- **阶段映射**：W1–W2 → [G3](3.G3-static-closed-loop.md)；W3 → [G5 阶段 5.2 伪动态](5.G5-conveyor-dynamic.md)；W4 前半 → 11-04 交付，后半 → G5 阶段 5.3；W5 → 真动态；W6 → [G6](6.G6-final-delivery.md)。G4 的平面映射作为 W3 的支撑项并行，不再是主线的硬前置。
- **门禁口径**：全程按[双轨制](0.1hardware_bringup.md)——**竞赛轨只保留红线门禁**，流程门禁留到周末归档。
- **场景约束（2026-10-14 定，不再变更）**：抓取背景**只有两种**——**黄色桌面**或**绿色传送带**。棋盘格路线已废（角点检出不稳、误检严重），不打印标定板、不跑角点检出、不单独求相机内参；像素→工作坐标靠平面上的实测点对。详见 [G4 方案](4.G4-static-vision-grasp.md)。

## 明确"跳过"清单（保护工期）

以下事项在本轮冲刺中**明确不做**，做了就是浪费工期：

| 跳过项 | 理由 |
| --- | --- |
| 训练任何深度学习模型（含 GraspNet/Graspness） | 无深度相机、无 GPU、39 天不可能；见 [G4](4.G4-static-vision-grasp.md) |
| 引入 ROS / MoveIt / Gazebo | 与现有 UIO + 裸 RTL 通路冲突，rootfs 也装不下 |
| 6 自由度解析逆运动学 | 5 关节 + 平面抓取，示教表 + 插值足够 |
| 完整 3D 手眼标定 | 平面抓取只需平面映射 |
| **棋盘格/标定板与相机内参标定** | 2026-10-13 实测角点检出不稳、误检严重；背景已固定为黄桌面/绿传送带，**平面上的实测点对会把畸变一起吸收**，不需要独立内参，见 [G4](4.G4-static-vision-grasp.md) |
| 通用背景鲁棒性（换桌布、换颜色、杂乱背景） | 背景已固定为两种工况；为其它背景调参不产生验收价值 |
| 100 次静态循环全量记录、逐条证据引用 | 归档轨事项，**不是运动前置条件** |
| 为竞赛轨填 `g3_station_plan.json` / `g3_observation_log.json` | 同上；需要时周末补 |
| `trajectory_engine.sv` / PL 侧 FIFO / 硬件 IRQ | PS 侧软状态机即可；无实测需求就不动 PL |
| DMA / HLS 加速 | 视觉是低频（每次抓取一帧），无带宽压力 |
| 动态"实时跟随" | 舵机节拍不允许，改预测拦截；见 [G5](5.G5-conveyor-dynamic.md) |
| 无人值守通宵跑 | 红线：运动期间必须有人在场 |

## 三条不可让的价值排序

当工期冲突时，按此顺序砍功能，**不砍红线**：

1. **保 11.04 的伪动态交付**（视频里必须看到"传送带在动、物块被抓住"；退无可退才退静态）
2. **保 11.20 的演示可用性**（宁可成功率 70% 能稳定演示，不要 90% 但会死机）
3. **保数据与文档**（答辩分数的来源）

→ 具体降级路径：
- 伪动态触发不稳 → 退回"固定 T + 物块定点投放"，仍算伪动态；
- 传送带完全跑不起来 → 静态抓取（W2 视频），文档里明确写"动态部分 11.20 完成"；
- 真动态视觉提前量没成 → 保留固定 T 的伪动态演示，答辩时如实说明"提前量为常值，视觉用于检测与验证"。
