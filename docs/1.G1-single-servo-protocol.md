# 1. G1：单舵机协议与物理层

## 目标

在一个隔离的 HX-30HM 舵机上，证明 FPGA 可安全发送并接收 1 Mbps、8N1、半双工协议帧。G1 只验证 PING/READ 和故障路径，不进行机械臂运动。

## 计划核心改动

- 为 `src/pl/rtl/servo_bus_master.sv` 实现 UART 发送、接收、校验和、超时和半双工方向切换状态机。
- 为 `src/pl/rtl/safety_monitor.sv` 接入急停、看门狗和协议故障，令其实际控制发送许可。
- 仅在已验证的收发器、引脚约束和独立硬件急停条件下，把舵机 IO 从包装器导出；不使用占位 XDC 引脚。
- 新增 PING、READ、畸形帧、校验失败、无应答和方向切换的 RTL 仿真。

## 验收证据

- 单个隔离舵机的 ID、上电空闲电流和逻辑分析仪波形。
- 1 Mbps PING/READ 的正确请求、应答和校验和记录。
- 急停、断线、超时与坏帧均能阻止发送并留下可观察故障。

## 阶段边界

G1 通过前不允许六轴连接、不允许 `SYNC WRITE`、不允许任何目标位置写入。
