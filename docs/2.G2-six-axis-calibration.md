# 2. G2：六轴标定与低速同步写

## 目标

建立六个关节的真实标定数据，并在清空工作空间、低速条件下完成受限的六轴 `SYNC WRITE`。

## 计划核心改动

- 当前已准备独立的 `g2_descriptor_guard` 与仿真：提交时原子快照六轴目标、速度、加速度和截止时间，并拒绝未标定、越限、故障/禁发和过期描述符。该模块**未接入顶层、AXI 命令提交或物理 UART 发送路径**；仿真通过不构成运动许可。
- 将实测关节 ID、方向、零位、最小/最大安全位置和回零姿态写入实际标定文件；模板 `config/arm_calibration.template.toml` 不可直接使用。
- 将 `COMMAND.ENQUEUE` 实现为原子描述符提交点：PS 先写完六轴目标、轨迹和截止时间，PL 再快照整条命令。
- 为已标定限位增加 PL 侧命令校验；无标定、越限、急停或故障时禁止发送。
- 完成 HX-30HM 目标位置、时间、速度字段与真实设备应答的核验。

## 验收证据

- 完整六轴 ID/零位/方向/限位表与回零姿态记录。
- 低速、清空工作空间下的单次与重复 `SYNC WRITE` 记录。
- 限位拒绝、软件停止和硬件急停的可重复故障测试。

## 阶段边界

本轮 G2 仅限离线代码与仿真。在真实标定、独立急停验收及用户另行明确授权实物动作之前，不发送任何实物写/运动命令。日后 G2 仅允许经过标定和限位检查的低速动作，不代表已具备连续轨迹或闭环性能。
