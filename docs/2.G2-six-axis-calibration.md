## 已交付的 G2 能力

- 六个唯一 ID 的命令闭区间与原始速度上限 1500 编入实际 TTL 顶层。PL 发前复核目标、参数、物理禁发、截止时间和总线占用。推荐原始速度 500；原始时间/速度字段不推定物理单位。
- ABI 0E 的**显式绝对目标不再预读起点**：单轴与六轴在 PL 完成检查后直接发各自唯一的运动 WRITE。相对 `calibrate-step` 与 `stop` 因功能需要仍保留发前 READ。
- 绝对命令 `start=UNAVAILABLE`、`actual_delta=UNAVAILABLE`（不得写成"位置未变化/已变化"）；发后仍报告 `last`、`target_error`、`in_band`。单轴要求正常 WRITE ACK + 有效发后 READ + PL 连续三次到位；六轴广播无 ACK，要求六轴各自有效反馈并完成连续三轮全轴到位。
- 命令故障只属于本次提交；**失败不自动重试**，总线空闲后由操作者再次显式提交。软件 `stop` 现场 READ 六轴后广播保持；独立断电急停是单独的硬件路径。
- 原先叫作 home 的六个数现称**测得的参考位置**。ID 2 在下限、ID 3/4 在上限，**不构成安全待机姿态**，且没有自动回位命令。

## ID 5 窄角度窗口：已定位并解除（不要再重复排查）

**结论（2026-10-10 定位 / 2026-10-12 解除）：** ID 5 舵机内部的角度限制寄存器 `0x09`/`0x0B` 曾被外部工具写成围绕 ~2000 的极窄窗口 **[1926, 2049]**，导致舵机在 WRITE 应答阶段（`elapsed_ms≈5`，尚未运动）直接以 `ERROR=0x10`（角度类）拒绝窗口外的绝对目标。**这与本仓库任何一版代码无关**——仓库内没有写 `0x09`/`0x0B` 的路径。

操作者已用幻尔官方软件重新校准，2026-10-12 的 `--target 1500` 实测通过即为证据。**0–4000 仍是命令范围标注，不是机械全程实测**；G3 首次工位标定时应补记其真实可用区间。

排查过程中确认的几点，供以后遇到类似现象时直接套用：

- **ABI 0D 的发前 READ 门禁把瞬时状态放大成全局锁死。** 舵机的 `0x10` 只持续约 12 s 即自行清零，但 0D 的"发前位置 READ 失败即整条命令作废"把它变成跨命令粘滞的持续失败，于是"越试越坏"。ABI 0E 删除该门槛后此现象消失。**这是本仓库历史上最严重的一次进度拖慢，也是"流程门禁不得阻塞运动路径"的直接依据。**
- **`engine_fault=8` 表示"校验通过的状态包中 ERROR 字节非零"**，不是超时。`servo_error_raw=0x10` 仅确定"角度类"状态。
- **`fault=12` + `write_sent=0`** 才是 PL 限位拒绝；**`fault=5` + `write_sent=0`** 是 0D 时代发前 READ 失败（帧没发）。两类日志不可合并解读。
- **`sweep` 伪影**：逐字节读 16 位字段的高字节位置（0x0A/0x0C/0x11/0x19/0x20/0x2B/0x2D/0x2F/0x31/0x39/0x3B/0x3D/0x44/0x46）会返回固定 `0xD0`；单字节 0x43 与 0x38 别名。**16 位字段一律用偶地址双字节读**，上述伪影不得写入任何结论。

证据归档：[ID 5 窗口归档](../artifacts/archive/g2-id5-angle-window-20261012/README.md)、[ID 5/ID 1 扫描对照](../artifacts/reports/sweep-id5-id1-20261010.txt)。

## 只读诊断通道

- **PL G1 只读白名单**：位置 `0x38`、扭矩开关 `0x28`。其它 HX-30HM 状态寄存器走 BusLinker USB 通路的 `dump` / `sweep`（严格只读，逐帧断言只发 READ）。
- **写回通路**（保留能力，当前不执行）：`rtcs-buslinker-g1 write-reg` 只允许单播写 `0x09`/`0x0B`/`0x37`，必须 `--confirm-write`，写前写后各读回一次，不重试。白名单外地址、缺确认、广播 ID 均一帧不发。可回退顺序：先 `0x37=1`（NVS 掉电不保存）再写窗口。
- **六轴 CLI 只有 `limits` / `diagnose` / `torque-status` / `move-six` / `stop`**；`inventory` 已删除（它是 `diagnose` 的严格子集，保留只会让人误用信息更少的那个）。
