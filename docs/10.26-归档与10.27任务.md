## 3. 三个技术判断被现场证实

1. **"稳定 0.5 s 才有效"是对的**：13 次没有一次单帧出点，最短也凑了 6 帧 0.50 s。
2. **"ID2 只告警不拦截"是对的**：x=300~311 时 `ID2 target 2057~2093 > 2020` 照实告警，
   四次全部抓成功；若当初做成硬门禁，这四次会被直接拒掉。
3. **"串口被占用时降级打印坐标"是对的**：一次 `PermissionError` 后仍打出
   `CAPTURE_POINT x=372.14 y=36.07`，没有静默失败。

## 4. 一句话的链路说明（写报告用）

```
相机 1280×720 → YOLO11n(PC/CPU) → 平面单应 → 稳定 0.5 s 判据
   → 单行 JSON 200 B → USB-UART 115200 → 板端 server
   → PS 六点五轴插值 → PL 组帧/限位/deadline → 六轴舵机 → 七步抓放
```

- 感知与抓取点决策在 **上位机**；
- 坐标→关节、状态机在 **PS**；
- 总线时序/限位/故障锁存在 **PL**。
三层的分界与"FPGA 是否只是转接板"的评估见 [FPGA 在项目中的作用](../docs/10-FPGA在项目中的作用与赛道符合性.md)。
