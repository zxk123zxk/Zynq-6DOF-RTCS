# Zynq-6DOF-RTCS 项目长期记忆

## 竞赛框架
- 赛事：全国大学生嵌入式芯片与系统设计竞赛 2026，AMD 赛道；目标**具身智能赛道（3.2）**：AI PC 端侧推理 + FPGA/Zynq 实时控制协同；选题方向"AI 机械臂抓取与控制"。
- 红线（AMD.pdf 3.2.2.3）："策略模型运行"属 AI PC 职责；FPGA 不得只是 USB/串口/GPIO 转接板；需指标表 metrics/ + 原始证据。
- 硬节点：**11.04 提交静态抓取作品文档+视频；11.20 决赛（动态抓取）**。双人分工：操作者=舵机/PL/PS/集成；A=视觉；B=结构/交付。

## 硬件与算力事实
- 板：ALINX AX7Z020（XC7Z020），PS/PL 直驱 6×HX-30HM 总线舵机；ID 1–5 关节、ID 6 夹爪；ABI 0x5254000E。
- 相机：幻尔 30 万像素/120° 广角 UVC，无深度。
- **本开发机无 CUDA**（torch.cuda.is_available()=False 实测）——本机训练只能 CPU 挂机或用免费云（Colab/Kaggle）。

## 视觉关键决策（按时间）
- 棋盘格路线已废（10.13 实测角点不稳）；背景锁死两种：黄色桌面/绿色传送带；不做内参标定，用平面实测点对求映射。
- 竞赛轨不区分类别（cube/cylinder 混淆已实锤），取最高置信度检测为目标。
- **10.15 根因定案**：绿带白方块不可检 = 光面 PVC 皮带镜面高光 + 自动曝光过曝，白高光冒充 cube、淹没真方块；桌面哑光故正常。治理顺序：压曝光（live_test 已支持 --auto-exposure/--exposure/--gain/--backend）→ 调灯/角度 → CPL 偏振片 → 仍不行才自训。
- **10.15 晚实测**：exposure=-5 下地面工况（低角度侧拍）识别稳定；桌面俯拍仍误检爆炸（1474 个检测大半为背景，conf≥0.5 仅 -75% 不清零）→ 根因=俯拍角+光面皮带+顶光镜面反射。
- **换相机决策（10.15 晚）**：购中奥维柯 3mm 90° 无畸变+偏振片，约 10.17 到货。**正式映射点对标定与自训数据采集均推迟至新相机到货后**——换相机=工况重置，旧相机上标定/训练数据都会作废。
- 自训预案：150–300 张 + 30 负样本，只标 1 类"工件"，yolo11n 迁移（不要从 2 类权重起步）；**训练已由队友明后天并行完成，不占 A/主线**；必须在新相机+反光治理后采集。移植包=src/vision/+models/vision/+requirements-vision.txt+REPRODUCTION_GUIDE_ZH.md+许可三件。
- 模仿学习（SO-ARM101.pdf 的 LeRobot/ACT）已评估否决（10.15）：非手眼标定（"handeye"仅相机名），需主臂+云 GPU+改 PL 连续流，20 天硬节点下无容错；保留作文档选型论证素材。

## 证据与文档惯例
- vision_runs/<run>/ 有 summary.json + detections.jsonl + annotated.mp4；取证帧归档 artifacts/reports/vision-diagnosis-YYYYMMDD/。
- 用户偏好：反对过度保守的测试仪式；文档要数据先行、结论先行；喷漆只喷方块不喷皮带（会弯折开裂）。
- 注意：10.14 系列文档（验收细则/命令清单/平面映射指南/相机选型/点检诊断）由用户自行精简删除，属有意清理；断链已于 10.15 全清至 0。用户偏好：文档宜少、及时删过时无用者。
- 工作方式（10.19）：推进过程中**命令直接在对话里给，不要写进文档**；等全部跑通后，再一次性同步文档与仓库正本。
- **禁止自作聪明的硬门禁（10.19 用户严令）**：任何会阻止既定任务继续执行的检查，默认只能是告警，不得 fail/exit/拒绝；只有用户明确要求拦截时才可加，并须在代码与文档标注"用户要求"。已写进 `CLAUDE.md`。
- **位点数值不得猜**：关节目标只能来自现场 `diagnose` 实测；没实测就不填，不凭几何推理编。
