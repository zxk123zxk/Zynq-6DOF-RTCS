# 2026-10-12

## 素材评估 + 竞赛冲刺计划（产出报告）

新增 `Material_Library/机械臂ROS入门教程-小五`（744MB，2365 文件），实为 4 个互不相关子工程：
- `catkin_UR5/` ROS1 UR5 + Robotiq + MoveIt（不可用）
- `graspness_/` GraspNet-Graspness 深度学习抓取检测（含 184MB 权重、pointnet2/knn/MinkowskiEngine）
- `ws_moveit (copy)/`、`ur_ws/`（ROS1/ROS2，不可用）

**可移植性结论（已写入报告）**：唯一真正有价值的是 `graspness_/real/` 与 `graspness_/utils/` 的**通用视觉件**——
`real/calibrate.py`（手眼标定 SVD + depth scale 优化）、`real/realsenseD41x.py`（相机封装）、
`utils/data_utils.py`（CameraInfo/点云）、`utils/collision_detector.py`、`real/robotiq_gripper.py`。
`UR_Robot.py` 只能参考 `R2rpy` 等旋转转换与抓取动作序列（UR socket:30003 不可用）。
**GraspNet 网络本体明确不可用**：需 CUDA + MinkowskiEngine + GraspNet 数据集，Zynq ARM 跑不了、39 天训不出。
同库 `kr260_robotic_arm-main`（KR260 + ROS2 + OpenCV 颜色分拣）比小五包更贴合本项目形态。

**计划可行性判断**：11.04 静态抓取可行（~75%，需"固定工位盲抓"兜底视频）；
11.20 动态抓取可行但紧张（~50%）。最大空白不是门禁，而是 **视觉 / 手眼标定 / 运动学（FK-IK）三个模块完全不存在**，
外加 **夹爪身份未知**（最致命）。

**对门禁的评估**：真红线保留（独立供电、物理禁发跳线、PL 限位/速度/截止时间、独立硬件急停）；
实验级流程门禁（逐步人工确认、离线 JSON 证据合同、每命令归档、P99/100 次循环）应移出竞赛轨。
关键实证：历史上最严重的拖慢 **是门禁自己造成的** —— ABI 0D 的发前 READ 门禁把舵机瞬时 ERROR 位放大成持续性全局锁死。
提出**双轨制**：竞赛轨（快，关流程门禁）+ 归档轨（慢，全门禁）。

**技术路线降级建议**：经典 CV（颜色/轮廓/ArUco）+ 几何位姿取代深度学习；
示教位姿表取代解析 IK；动态用"预测 + 定点拦截"取代真跟随（HX-30HM 节拍慢）；传送带先 stop-and-go。

产出：`artifacts/reports/competition-plan-material-assessment-20261012.md`（含六周计划表、M1–M4 里程碑、推进流程）。
未改动任何源码/RTL/CLI/镜像，无需重建，回归状态不变。
