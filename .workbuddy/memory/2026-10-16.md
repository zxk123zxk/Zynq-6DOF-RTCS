## 给板端 rootfs 加 python3（方案 A 落地）

- 根因：板端 PetaLinux 精简 rootfs 无 python3，编排层 Python 脚本无法跑。
- **构建环境定位**：PetaLinux 2023.2 装在 WSL 内 `/home/zxkzxk/tools/petalinux/2023.2/settings.sh`（source 后 petalinux-build/config/package 可用，Ubuntu 22.04 报 "not a supported OS" 但能构建）；工程目录 `/home/zxkzxk/projects/zynq/petalinux-rtcs`（10.13 有构建产物）。
- 加 python3 方式：新增 `src/ps/petalinux/meta-user/recipes-core/images/petalinux-image-minimal.bbappend`，`IMAGE_INSTALL:append = " python3-core python3-json python3-misc"`；create_project.sh 已加同步该 bbappend 的逻辑；已 cp 到工程。
- 注意：PetaLinux 2023.2 的 python3 是 3.10.x 无 tomllib，g3_offline_plan 已有回退解析。
- 构建已后台启动；完成后需 `build_sd_image.sh <工程目录>` 打包 BOOT.BIN/image.ub 并校验，再烧录 SD。
- 风险：加 python3 后 rootfs.ext4（现 72MB）会变大，image.ub 相应增大，SD 分区需够。
- 构建日志在 artifacts/logs/petalinux-build.log（build_sd_image.sh 自动 tee）。
