# ABI 12 before ABI 13 rebuild

This directory preserves the ABI 12 hardware and SD files present in the
working tree immediately before the ABI 13 diagnostic/UIO changes. File hashes
are in [SHA256SUMS](SHA256SUMS). The SD image includes the read-only six-axis
`diagnose` command. Do not mix these files with ABI 13 products.
