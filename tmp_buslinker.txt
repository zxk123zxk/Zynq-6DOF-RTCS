1. BusLinker V3.0舵机调试板使用手册
1.1 产品介绍




BusLinker V3.0舵机调试板是一款舵机调试工具，通过附带的上位机软件ServoStudio，来测试舵机和设置舵机参
数。同时调试版还能与单片机之间进行串口通讯，以此来控制舵机，它的6大特点为广大用户带来良好的体验：

   支持舵机串行总线连接，兼容PH2.0、5264、1.25T接口，全面适配幻尔磁编码智能总线舵机，实现即插即用
   式连接。

   内置8档可配置波特率，最高支持1000000波特率，内置8档可配置波特率，满足多场景控制需求。

   兼容多样化控制器，板载通讯切换接口，可灵活切换ESP32、STM32、Arduino、树莓派、JETSON等控制器。

   多种通讯方式，支持UART、USB、单线TTL三种通讯模式，通过通讯指令即可快速控制舵机运动。

   双供电输入设计，提供高电流DC及端子两种供电方式，支持5-14V宽电压输入，稳定可靠。

   支持二次开发拓展，预留扩展串口，配套提供通讯例程，便于功能拓展与深度开发。

   迷你尺寸，采用小巧的结构设计，有效减少空间占用，提升机器人整机集成度与设计灵活性。

   兼容LeRobot项目，兼容LeRobot项目，适配性拉满。

（1）基础配置

① 基本设置
在这个模块中，我们可以更改舵机的ID号和上位机与舵机通信的波特率，ID号为1~253，波特率有8种可选。

② 运行模式




在这个模块中，可以把舵机设置为3种模式：位置模式、闭环速度模式、开环速度模式。

在位置模式下，舵机将会以舵机模式运行。在闭环速度模式与开环速度模式下，舵机会以电机模式运行。

③ 功率控制




用于设置舵机的最小输出启动扭矩和最大输出扭矩限制，设1000 = 100% * 堵转扭力。

   Note

 注意：如果设置的扭矩过小，舵机可能会无法转动。

（2）运动控制
① 位置控制参数




   位置校正：用于校正舵机偏差，阈值为-2047~2047。如果在安装舵盘时发现有偏差无法以十字姿态安装，可以
   调节这个参数进行偏差的调节。

   最小/最大角度限制：用于限制舵机转动的角度范围，阈值为-3071930719。在绝对位置模式下，舵机转动的最大位置

   范围为-3071930719，舵机转动的位置04095对应着角度0360°，所以舵机转动的最大范围约为±7.5圈。可根据个人
   需求在这个范围内设置舵机转动的范围阈值。

② 位置闭环参数




三个参数用于调节舵机的位置误差，P参数决定了当前位置误差对控制信号的影响；I参数是为了减少长期存在的静态
误差（正常不需要调节）；D参数减小误差变化的速率，从而增强系统的稳定性。用户可根据自身需求调节这三个参
数的值，达到自己的预期效果。

③ 速度闭环参数
两个参数用来调整舵机的速度误差，确保其按预定速度进行运动并保持精确的速度控制。用户可根据自身需求调节这
两个参数的值，达到自己的预期效果。

（3）安全保护




用户可根据自身不同的需求来调节各个模块的阈值以及选择产生保护和报警的对象。

1.欠压/过压阈值为0~254，单位为0.1V。

2.过流阈值为06000，单位为mA；过流保护时间阈值为0254，单位为10ms。

3.过载阈值为0100，单位为1%，最大为最大扭矩；过载时间阈值为0254，单位为10ms；过载扭矩为触发过载保护后的最大输
出扭矩，阈值为0~100，单位为1%。

4.过温保护阈值为0~100，单位为°C。

1.2 幻尔HX-30HM总线舵机通信协议文档
修改记录


             发行版本                     变更点                               日期

              1.0                    初始发行                            2025/09/25


1.2.0 概要
    该通信协议内容适用于HX-30HM磁编码总线舵机。舵机采用ARM 32位单片机为主控制芯片，其位置感应采用
    360度12位精度的磁铁感应角度方案。

    一个总线控制网络中允许有多个舵机，所以每个舵机都分配有一个网络内唯一的 ID号。控制器发出的控制指令
    中包含 ID 信息，只有匹配上 ID 号的舵机才能完整接收这条指令，并返回应答信息。

    通信方式为串行异步方式，通过UART 异步串行接口统一控制。通信速度为1 Mbps，一帧数据分为 1 位起始
    位，8 位数据位和 1 位停止位，无奇偶校验位，共 10 位。

    详细的控制内容见HX-35HM内存表


1.2.1 指令包
指令报格式：


   字头           ID号      数据长度        指令                   参数                       校验和

 0xFF 0xFF          ID   Length   Instruction   Parameter 1 ...Parameter N        Check Sum
1. 字头：连续收到两个 0xFF ,表示有数据包到达。

2. ID 号： 每个舵机都有一个 ID 号。ID 号范围 0～253，转换为十六进制 0x00～0xFD。其中ID 号 254 为广播 ID,若
控制器发出的 ID 号为 254(0xFE)，所有的舵机均接收指令，除 PING 指令外其它指令均不返回应答信息(多个舵机连接
在总线上不能使用广播PING 指令)。

3.数据长度：等于待发送的参数 N 加上 2，即“N+2”。

4.指令：数据包操作功能码，详见 1.2.3 指令类型。

5.参数：除指令另外需要补充的控制信息，参数最大支持双字节参数表示一个内存值，字节顺序参考见HX-35HM内存
表。

6.校验和：计算方法如下：

Check Sum = ~ (ID + Length + Instruction + Parameter 1 + ... Parameter N)

若括号内的计算和超出 255, 则取最低的一个字节，“~”表示取反。


1.2.2 应答包
应答包是舵机对控制器的应答，应答包格式如下：


     字头            ID 号       数据长度          当前状态                        参数                  校验和

   0xFF 0xFF        ID        Length         ERROR           Parameter 1 ...Parameter N    Check Sum


    1. 返回的应答包包含舵机的当前状态 ERROR，若舵机当前工作状态不正常，会通过这个字节反映出来（各状态所
      代表意义详见HX-35HM内存表），若 ERROR 为 0，则舵机无报错信息。

    2. 若指令是读指令（READ DATA），则 Parameter 1 ...Parameter N 是读取的信息。


1.2.3 指令类型
总线智能舵机通讯协议可用指令如下：


                指令                                       功能                          值      参数长度

            PING(查询）                                 查询工作状态                         0x01       0

          READ DATA(读）                            查询控制表里的字符                         0x02       2
