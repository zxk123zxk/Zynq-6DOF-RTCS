## 4. 四个值得记下的观察

1. **同一物理点重复读数 ±0.15 mm**（372.17/372.16/372.43）：说明帧稳定、单应没漂，
   重复摆件的位置差就是真实摆件差，不是视觉噪声。
2. **稳定判据不是摆设**：13 次全部靠 6~7 帧累计 0.50 s 才判有效，
   没有一次是单帧直接出点。
3. **ID2 告警在低 x 段如实触发且未阻断**：x=300/307/309/311 时
   `approach: ID 2 target 2057~2093 above operating hint 2020`，
   四次全部抓取成功 —— 印证"只告警不拦截"这个选择是对的。
4. **串口被占用时降级正确**：第 2 次 `PermissionError` 后仍打印了
   `CAPTURE_POINT x_mm=372.14 y_mm=36.07`，没有静默失败，坐标可人工兜底。
